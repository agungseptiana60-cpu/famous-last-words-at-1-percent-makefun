The funniest last words a phone could say as its battery hits 1 percent: a secret-keeper phone that watched its owner type, delete and retype a message at 2 a.m. — and is dying before it can tell anyone. No will, no goodbye to the charger, no pun on 1 percent: the dying battery is the scene, not the joke. The program in `main.ts` writes that single line (95 characters) to `entry.txt` in the output directory.

## Run it

```sh
node main.ts
```

This writes `/output/entry.txt`. Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose the output directory.
